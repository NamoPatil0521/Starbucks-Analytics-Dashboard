☕ Starbucks Analytics Dashboard | Power BI

📌 Project Overview

The Starbucks Analytics Dashboard is an interactive data visualization project developed using Microsoft Power BI. It analyzes Starbucks-related data through KPI cards, beverage analysis, geographical visualizations, and interactive filters to make data exploration easier and more insightful.

🎯 Project Objectives

- Analyze Starbucks' global presence and geographical distribution.
- Explore coffee and beverage categories.
- Identify the Top 5 highest-caffeine beverages.
- Present key insights using KPI cards and visualizations.
- Enable interactive data exploration using slicers and filters.

🛠️ Tools & Technologies

- Microsoft Power BI – Dashboard development and visualization
- DAX – Calculated measures and KPI analysis
- Data Cleaning & Transformation – Preparing data for analysis
- Data Visualization – Presenting insights through interactive charts

📊 Dashboard Features

- 🌍 Global Presence Analysis: Explore the geographical distribution of Starbucks locations.
- 📈 KPI Cards: Display key metrics and important summary figures.
- ☕ Beverage Analysis: Explore different beverage categories and their characteristics.
- ⚡ Top 5 Caffeine Analysis: Identify beverages with the highest caffeine content.
- 🎛️ Interactive Filters: Filter and explore dashboard data dynamically.
- 📊 Visual Analytics: Present data through charts and other visual elements.
